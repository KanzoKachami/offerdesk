# Отложено: «Потоки»

Раздел «Потоки» пока на паузе (в меню помечен «скоро»). Здесь лежат готовые страницы,
чтобы потом вернуть их без переписывания:

- `streams-page.tsx` → вернуть в `src/app/(app)/streams/page.tsx`
- `streams-import-page.tsx` → вернуть в `src/app/(app)/streams/import/page.tsx`

Компоненты и действия остались на своих местах: `components/stream-*.tsx`, `lib/launch-actions.ts`, `lib/parse-streams.ts`.
Автосоздание потоков в базе выключено файлом `supabase/007_streams_off.sql`.
